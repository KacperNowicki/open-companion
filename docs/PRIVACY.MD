# Privacy Policy

OpenCompanion is a local-first, open-source desktop application.

## Local app data

OpenCompanion may store local configuration, runtime state, logs, memory files, vault files, and generated assets on the user's own device. Users control this local data.

## Cloud providers

OpenCompanion uses local Ollama models by default. If a user configures a cloud AI provider or external service, the data sent to that provider is governed by that provider's own privacy policy and terms.

## Payments

Optional support/tip payments may be processed by Stripe. Payment information is handled by Stripe, not directly by OpenCompanion.
